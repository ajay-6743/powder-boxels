# 🧪 Powder Box (Pixels Boxels)

A high-performance, browser-based falling-sand simulation engine featuring **thousands of elements**, advanced chemical reactions, thermodynamic state changes, and interactive cellular behavior.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![HTML5 Canvas](https://img.shields.io/badge/Tech-HTML5%20Canvas%20%2F%2F%20JS-orange)](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API)

---

## ✨ Features

* **Massive Element Catalog:** Explore over 1,000+ elements spanning periodic table components, organic chemistry, minerals, alloys, food items, complex chemicals, and living creatures.
* **Complex Chemistry & Reactions:** Real stoichiometry and thermal equations mapped across elements (e.g., acid-base neutralization, metal displacement, oxidation, and combustion).
* **Thermodynamics & Phase Changes:** Dynamic heating and cooling elements that transition states (e.g., Ice $\rightarrow$ Water $\rightarrow$ Steam, or metal melting points).
* **Life Simulation:** Organisms that walk, swim, fly, eat, breed, and decay.
* **Interactive Lookup & Tools:** Built-in search lookup modal to check recipes, behaviors, and reactions for every single element.
* **Save / Load States:** Persistent local storage slots to save and restore your sandbox creations.
* **Responsive Layout:** Works smoothly on desktop and mobile browsers with native pointer/touch support and safe-area inset compatibility.
